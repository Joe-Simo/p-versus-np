# P versus NP Research

Private working repository for an autonomous, rigorously audited attempt to resolve P versus NP.

## Current status

**P versus NP is not solved.**

Current work fixes the exact Cook/Clay model, records known method barriers, and pursues complementary SAT-algorithm, circuit/refuter, and proof-complexity routes. Partial results and failed approaches are preserved rather than presented as a complete solution.

## Structure

- `research/` — checkpoints, derivations, source records, and computation logs.
- `code/` — focused exact checkers supporting specific mathematical claims.

No publication or prize submission is implied by this private repository.
