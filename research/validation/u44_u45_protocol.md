# U44-U45 pre-execution contract

Date: 2026-09-15. Scope: /mnt/data/02-p-versus-np only. No P versus NP solution is claimed.

Question: for n<=3, what are the exact small fan-in-two circuit classes, their shortest inconsistent partial truth tables, and their least-degree GF(2) separating polynomials? Does low-degree nonlinear consistency overcome U43's full-linear-span obstruction, and what universal interpolation constraints survive?

Circuit model B2: constants 0 and 1 and n uncomplemented input wires are free. Each charged gate computes any of the 16 binary Boolean functions, with ordered, possibly equal predecessors. Fan-out is unrestricted; NOT is a charged binary gate unless absorbed into another operation. Output can be any available wire. Truth-table bit x corresponds to the binary expansion of integer x with x_0 least significant. A gate's opcode bit (2*a+b) specifies its output.

Synthesis: breadth-first sets of available wire functions, retaining one actual ordered gate list per set. Only functionally redundant gates are pruned; duplicate available sets are merged. Completeness requires the proof that arbitrary future gates depend only on the available functions, not their construction history. Distinguish this semantic state count from the raw ordered description count, which is independently enumerated through two gates and analytically counted at higher budgets. Full layers needed for minimality must finish; stopped layers will not be labeled complete.

For each synthesized budget, enumerate every n-input Boolean target and every subset of its 2^n locations. Find smallest inconsistent subset by direct consistency tests. Separately, over GF(2) construct the evaluation vectors of all squarefree polynomials in truth-table coordinate variables, compute exact ranks, and locate the first degree at which the target evaluation escapes the circuit-class row span. Preserve explicit synthesis witnesses, smallest anticheckers, and separation polynomials; verify each by direct gate or polynomial evaluation.

Follow-up theorem tests: implement partial-label decision-tree interpolation, charging all multiplexers in B2 gates; construct sparse truth tables by minterms; verify Hamming-ball evaluation matrices have full rank in degree <=radius. n=1 sparse-construction exceptions must be treated separately. These are construction and invariant tests, not runtime lower bounds.

Arithmetic: bounded truth-table masks (at most 8 bits for synthesis), bigint GF(2) feature vectors and raw description counts. No floating-point rank, randomness, SAT solver, learned model, or external oracle. Existing code/results remain untouched. Strict TypeScript and no-unused checks, compiled syntax checks, and independent Wolfram checks will be run if the existing allowance permits; failures are recorded rather than counted as passed evidence.

Follow-up before second run: extract the exact cubic zero-set identity for the three-input two-gate class and independently characterize this class by compatible cofactors. Build a uniform full-truth-table anti-checker generator for the fixed two-gate budget on arbitrary arity, with at most eight sampled inputs; exhaust all 65,536 four-input functions and directly check each returned certificate against every separately enumerated two-gate function. The asymptotic arity claim requires the essential-variable reduction proof; the finite tests alone do not establish it.

Follow-up before third run: improve the universal fixed-two-gate bound from eight to seven by sharing two sensitive edges at one vertex. A Boolean function with maximum sensitivity <=1 is constant or a literal; therefore a function with four essential variables has such a vertex. Verify the seven-point algorithm on all four-input functions again, plus one six-input multiplexer where information is routed among four data inputs. This is a targeted test of the new sharing argument, not a large-domain exhaustive claim.

Follow-up before fourth run: remove all synthesized-table lookups from the uniform algorithm itself. Accepted cores are reconstructed directly by their two compatible cofactors. Rejected three-variable cores return seven points by evaluating the cubic on eight one-bit neighbors; the finite lemma says its nonzero set has no isolated point. Enumeration remains only in the independent validation, not inside the delivered fixed-budget algorithm.
