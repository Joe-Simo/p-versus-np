# U11 — Equality track: polynomial-size CNF with 2^m pairwise inequivalent residual Boolean functions

Date: 2026-09-14
Status: proved as written, with independent exact finite verification for m<=8; no P versus NP resolution.

## 1. Target

U10 showed that a natural boundary-clause summary can have 2^m distinct states. The stronger question is whether this exponential blowup survives the strongest possible semantic merging rule: identify two separator assignments whenever the *entire residual Boolean functions* on the remaining variables are logically equivalent.

We answer yes with an explicit linear-size CNF family.

## 2. Construction

For m>=1, let separator variables be x_1,...,x_m and remaining variables y_1,...,y_m. Define

    F_m(x,y) = AND_{i=1}^m (NOT x_i OR y_i).

This is a 2-CNF with exactly m clauses and 2m variables.

For an assignment alpha in {0,1}^m to x, the residual formula on y is

    R_alpha(y) = F_m(alpha,y)
               = AND_{i: alpha_i=1} y_i.

Indeed, when alpha_i=0 the clause (NOT x_i OR y_i) becomes True; when alpha_i=1 it becomes y_i.

## 3. Theorem U11.1 — all 2^m residual functions are pairwise inequivalent

For distinct alpha,beta in {0,1}^m, the residual Boolean functions R_alpha and R_beta are not logically equivalent. Therefore F_m induces exactly 2^m pairwise inequivalent residual Boolean functions after assigning the separator variables x.

### Proof

Take alpha != beta. Choose j with alpha_j != beta_j. Without loss of generality alpha_j=1 and beta_j=0.

Set y_j=0 and set y_i=1 for every i != j. Then

- R_alpha(y)=0 because alpha_j=1 contributes the conjunct y_j;
- R_beta(y)=1 because beta_j=0 contributes no y_j conjunct, and every remaining required y_i equals 1.

Hence R_alpha and R_beta differ on this y-assignment and are not equivalent. Since there are 2^m assignments alpha, there are exactly 2^m inequivalent residual Boolean functions. QED.

## 4. Complexity of the original CNF

The original formula F_m has only m binary clauses and O(m) symbols under any standard variable-index encoding up to the ordinary logarithmic naming overhead. Thus the exponential family of residual semantic states is generated by a polynomial-size (indeed linear-clause-count) CNF.

This directly refutes the candidate universal compression principle:

    'After assigning m separator variables, quotient residual formulas by complete Boolean equivalence; only polynomially many semantic states remain.'

Even the perfect quotient by full logical equivalence can have 2^m classes.

## 5. Exact Wolfram verification

Wolfram Language independently evaluated the family for m=1,...,8. For every separator assignment it substituted the x-values, minimized the resulting Boolean expression, then deduplicated residual forms using exact `TautologyQ[Equivalent[...]]` tests.

Observed triples {m, distinct residual functions, 2^m} were:

    {1,2,2}, {2,4,4}, {3,8,8}, {4,16,16},
    {5,32,32}, {6,64,64}, {7,128,128}, {8,256,256}.

This finite computation is a consistency check only; the theorem above proves the statement for every m.

## 6. What this does and does not establish

Established:

1. Polynomial-size CNFs can induce exponentially many pairwise inequivalent residual Boolean functions after assignment to a separator.
2. Therefore any dynamic program whose state is exactly the residual Boolean function may require exponentially many states on this family.
3. U10's exponential phenomenon was not an artifact of a coarse boundary summary; it survives the finest possible semantic quotient by logical equivalence.

Not established:

1. This is not an exponential lower bound for SAT.
2. F_m itself is easy: it is Horn/2-CNF and can be solved in polynomial time by algorithms exploiting structure other than residual-state enumeration.
3. The result therefore rules out a class of memoization/decomposition runtime arguments, not all possible SAT algorithms.

## 7. Research consequence

The equality-track lesson is sharper now: any successful polynomial-time SAT algorithm cannot rely on a universal theorem that arbitrary separator assignments collapse to polynomially many residual semantic functions. Exponential semantic diversity already occurs in very simple SAT classes.

A viable equality route must exploit additional algebraic, proof-theoretic, or combinatorial structure that allows many semantically distinct residual functions to be handled collectively without materializing one state per function.

## 8. Next executable direction

Test an algebraic aggregation idea: represent the set of residual constraints by a compact polynomial or generating-function object and update that object without enumerating all residual functions. The first decisive check is whether exact coefficient/monomial growth becomes exponential on an explicit CNF family, or whether a nontrivial compressed invariant survives.

No statement here resolves P versus NP.
