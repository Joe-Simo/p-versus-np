# U48-U49 computation contract (written before the new runs)

Scope: explicit n-input truth tables, B2 gates (all sixteen binary Boolean operations), free constants and uncomplemented primary inputs; source size gap S vs floor(S/(10*n)). No larger fixed gate-budget exploration is the research target.

U48 tests an adaptive-query/hypergeometric lemma, circuit-description counts, and the sparse interpolation reason a certificate must contain several positive labels, not just one. Exact large-parameter results are exponent/rational certificates; no gigantic hard truth table is constructed. Small enumeration is a sanity check of a separately proved counting argument. Query algorithms have no target-dependent advice or preprocessing other than charged truth-table queries. They may use arbitrary computation between queries and may output unqueried addresses.

Tests: enumerate all weight-w supports for N=2,4,8 and for w<=4 at N=16; for every K<=N compare four deterministic adaptive distinct-query policies with the exact hypergeometric histogram. Enumerate raw ordered B2 circuits with arbitrary output signal through two gates at n<=3 and one gate at n=4, preserving multiplicities. For all 3^8 consistent partial labelings, check explicit sparse positive-point interpolation. Test conditional query bounds using actual finite circuit-class nonmembers, while labeling those cases as small-model checks, not as asymptotic gap instances.

U49 tests a fully charged binary-gate majority constructor on all assignments for odd lengths 1..19, and constructs larger odd instances only for gate counts. It tests exact weighted version elimination, function-uniform elimination and multiplicatively perturbed survivor counts on all 256 three-variable target tables against the <=2-gate class. Circuits are fully enumerated; this is not an efficient implementation for growing budgets. Check each returned refutation against the whole finite class and each positive outcome by its synthesized function. Cardinalities of returned certificates are not claimed minimal.

Arithmetic: bigint for combinatorial counts and rational comparisons, Number only for bounded truth-table masks, indices and counts demonstrably below 2^32. Primary implementation TypeScript; independent Python and a bounded Wolfram call will check different representations where useful. Existing files are not overwritten. A failed or incomplete call is not counted as evidence; successful logs are captured after execution.

Post-first-run amendment: the perturbed-count loop stalled on a finite target not satisfying the asymptotic hardness promise. The final finite experiment records an exact-count fallback on zero progress; it separately asserts that this is never needed when the best survivor count is <=15/16 of the current mass. No running-time improvement is inferred from this fallback. The initial strict type errors and failed assertion are preserved, not counted as successful checks.
